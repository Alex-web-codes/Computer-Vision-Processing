# Computer Vision Processing

A collection of computer vision, document image analysis, and structural extraction pipelines built in Python.

## Projects & Modules

### 1. [Timetable-Parsing](./Timetable-Parsing)
A deterministic multi-format schedule extraction pipeline and REST API server for PDF documents and raster images (PNG, JPG, BMP). Uses OpenCV morphological line detection, vector line-intersection stream extraction (`pdfplumber`), heuristic schema normalization, and PyTesseract OCR.

---

## Status & Roadmap

Additional computer vision processing projects are currently under active development and will be added to this repository:
- **Document Layout Analysis & Block Detection**: Structural region segmentation for multi-column documents.
- **Image Preprocessing & Binarization Suite**: Adaptive deskewing, shadow removal, and contrast optimization for noisy document scans.
- **Form & Grid Field Extraction**: Automated key-value pair and tabular bounding box parser.
